    G-One: a multi-agent assistant that does real tasks

    Most chatbots stop at the answer. G-One goes further. A central router sends each request to a specialist agent (Email, Research, Finance or DeepSearch), and a deterministic validation layer checks every action before it runs. That gate cut wrong actions more than any prompt tweak I tried.

    • React / Next.js
    • FastAPI
    • MongoDB
    • Ollama + Mistral
    • LoRA adapters
    • Voice input

    Built during the Vodafone (VOIS) and Edunet Foundation internship, guided by Prof. Sudhanshu Gonge. The widget at the top of this page is a tiny, rule-based version of the same idea.
